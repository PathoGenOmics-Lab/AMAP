AMAP run

How the run went, genome by genome and gene by gene

1 · Annotation quality

Did each genome annotate well?

One row per genome. Values far from comparable genomes are flagged, and a click on a row opens that genome.

2 · Reference map

Where on the reference are genes missing or broken?

Every reference gene at its place on the reference, one row per genome, grouped by lineage. Deletions that several genomes share stand out as blocks. Drag across the map to zoom into a region and list its genes.

3 · Gene lookup

What happened to one gene in every genome?

Search by locus, gene name or product. The gene's state, place and length in each genome, next to what the reference says of it.

4 · The correction

What did AMAP change in Bakta's annotation?

From Bakta's calls to the final genes: what each case kept, what the reference replaced, and what it added where Bakta called nothing. Click a bar for its genes.

5 · Pseudogenes

Which genes are broken, and in which lineages?

Every gene AMAP flags as a pseudogene in at least one genome, with the reason. Pseudogenes shared by a whole lineage come first.

6 · Beyond the reference

What do the genomes carry that the reference does not, and in how many copies?

Genes with no reference counterpart, how the reference genes are shared across genomes, the genes found more than once, and the pangenome when the run built one.

7 · Functional profile

Do the lineages differ in function?

Functional categories by lineage, the categories that differ most first.

8 · Methods and provenance

How was this made?

The version, the reference, the parameters and the software behind every number above, and what each state in this report means.
