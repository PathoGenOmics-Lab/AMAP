Overview

What goes into a decision, and the five outcomes.

2 min read

On this page
  • The three inputs to a decision
  • The pipeline
  • The correction itself
  • Next steps

AMAP does not annotate genomes from scratch. It takes an annotation that already exists, compares it against one that is trusted, and adjudicates the differences.

The premise is that de novo annotators are good at finding genes and less good at their exact boundaries. Bakta will call a start codon a few codons late, or split one gene into two, or invent a short ORF that is not really there. If a curated reference for a close relative exists, those errors are visible: align the reference proteins onto the new genome, and where the two disagree, decide which is more likely right.

On genomes of the Mycobacterium tuberculosis complex (MTBC) that adjudication changes roughly 30% of genes.

The three inputs to a decision

#

The Bakta annotation. Every CDS Bakta called on your genome, with coordinates and a locus tag.

The miniprot alignments. Every reference protein aligned onto your genome, with the coordinates where it landed. The reference proteins carry their own coordinates in their headers (Rv0001_1-1524), which lets a later step tell a real locus from a paralogous placement.

The false-positive set. Proteins that a de novo annotator calls on the reference genome itself but that are not in the curated annotation. Bakta's characteristic mistakes, in other words. For MTBC this is a curated file; with a custom reference AMAP derives it by annotating the reference and taking the difference.

The pipeline

#

Eleven steps, from genomes to reports:

  1. eggNOG database setup, skipped if it is already built
  2. Lineage typing with pathotypr, MTBC only
  3. Annotation with Bakta
  4. Protein alignment with miniprot
  5. Case classification: every CDS sorted by how it relates to the reference
  6. Correction: conflicts resolved, missing genes rescued, stop codons checked
  7. Functional annotation with eggNOG-mapper
  8. Duplication analysis: within and across genomes
  9. Pangenome with pangene
  10. The full report, final_report.html, after eggNOG
  11. The report by question, amap_report.html, in every run

The workflow page walks through each with its inputs and outputs.

The correction itself

#

Steps 5 and 6 are what makes AMAP more than a wrapper. Every CDS is sorted into one of five outcomes:

CaseMeaning
Case 1Bakta called it, the reference has nothing there. Potentially novel.
Case 2Coordinates match the reference exactly. Kept.
Case 3Coordinates match but alignment length differs. Kept.
Case 4Overlaps a reference gene, but the coordinates conflict. Must be resolved.
MissingThe reference has a gene there, Bakta missed it. Rescued.

Cases 1 and 4 are where the work is: deciding which novel genes are real, and which set of coordinates wins a conflict. The correction algorithm gives the rules and the thresholds.
